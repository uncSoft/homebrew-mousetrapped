# homebrew-mousetrapped

Homebrew tap for [Mousetrapped](https://github.com/uncSoft/Mousetrapped),
the menu bar panic button that rescues a trapped, hidden, or lost mouse
cursor.

## Install

```bash
brew install --cask uncSoft/mousetrapped/mousetrapped
```

## Uninstall

```bash
brew uninstall --cask mousetrapped        # remove the app
brew uninstall --zap --cask mousetrapped  # also remove preferences
```
